# 生物质与呋喃检索基准 v0.1.0（AI候选版）

本目录包含60题、冻结语料、逐对判断账本及真实检索运行记录。frozen scope 当前有1,194/1,312个组合具备有效等级，118个保持 `exhausted_unresolved`；**候选集和 Agent review 标签不等于经领域专家验收的完整金标。** 当前状态、维护流程和发布限制以 `EVALUATION_GUIDE.md` 为准，尚未判断的块不得按不相关处理。

## 来源与冻结

- 来源是项目现有官方库，不包括私人库和临时会话资料。快照时物理库51篇、929页、5,444块、5,444条向量；按现有页级安全及作用域规则实际导出48篇、5,066块。
- `snapshot/corpus.sqlite3` 通过SQLite只读连接与backup API生成，包含WAL中已提交的数据；快照不用于记录检索请求。测试运行使用独立副本。
- `manifest.json` 记录冻结时间、快照及语料SHA256、代码指纹、模型维度和切块版本。标题元数据在候选版首次发布前根据快照页面修正，修订前后哈希和原因均已记录；ID及正文不变。
- `doc_id` 直接使用原索引的 `chk_*`，`source_id` 使用内容哈希派生的 `paper_*`。文件名仅用于来源追溯，不是稳定ID。
- 原始切块为混合 `structure-v1` / `structure-v2`；保留页范围、ordinal、overlap、parser/chunker版本和原文哈希。此任务不重新切块，不修复原PDF，也不把问题写入知识库。
- 48篇标题均对照快照页面核验。原始章节缺失时保留null；作者、年份等未完成可靠结构化提取的字段留空，不从文件名猜测。DOI仅在首页存在唯一可识别值时填写。
- `sources.jsonl` 保存来源说明；语料含综述、实验论文及历史期刊重印内容。没有额外补入专利或外部知识。文献原有权利不因本测试集而改变；本目录是本地科研评测产物，不是已授权公开再分发包。

## 问题设计

| 主类型 | 数量 |
|---|---:|
| 基础事实 fact | 9 |
| 定义 definition | 6 |
| 反应条件 condition | 9 |
| 反应机理 mechanism | 9 |
| 实验数据 data | 6 |
| 比较 comparison | 6 |
| 多文档 multi_document | 6 |
| 条件约束 constraint | 3 |
| 语义改写 paraphrase | 3 |
| 无答案 no_answer | 3 |

- 中文42、英文18；简单18、中等30、困难12。
- 60题均由AI依据冻结证据编写，人工编写0题，合成比例100%。其中包含旧调优事实的开发集改写；不能声称完全独立的新测试事实。
- 出题涵盖木质纤维素组分及预处理、糠醛、HMF、CMF、FDCA/PEF、双相分离、DES、催化活性及机理、实验数值、原料差异和下游转化。
- 多数问题明确指定论文/研究体系，以避免不同条件、不同计量基准或不同年代的证据混用。该设计不能代表所有开放式研究问题。
- `domain` 为内部证据族标签（例如sn=SnCl4/EMIMBr，des=LiBr/DES，phos/phosphoric=磷酸分级，euc=桉木集成炼制，ga=ChCl/GA，sac=单原子HMF氢化，flash=闪速热解，photo=光催化，pef/fdca=呋喃聚合物）；它不是规范化化学本体。

## 标注方法及当前质量边界

每题应判断全部5,066块，共303,960对。`annotation_records.jsonl.gz` 始终包含全部组合：已判断项为0～3，待判断项为 `relevance: null`、`review_status: UNJUDGED`。`qrels.tsv` 只导出已明确判断的组合，绝不为凑满数量填0。全量完成前，普通评测汇总默认拒绝给出正式质量指标。

最初的99条种子判断来自已阅读的证据，并在同一来源的真实块中检查完整证据引文。它们只证明这些正例存在，不证明其他块不相关。`annotate.py` 随后逐批把完整文本与全部问题送入语义判定；返回必须覆盖全部输入组合，非零标注必须有可在原文定位的引文，错误或截断响应不会被当作成功。

分数3为能独立支持大部分或全部核心事实；2为直接且必要但需其他证据；1为辅助背景；0为没有可用支持。二值阈值为2，nDCG使用 `2^rel−1`。多文档题允许全部必要证据为2级。

复核计划包括所有非零标注、真实Top-5干扰块，以及按每题/每来源分层抽取10%的0级判断。第二轮不给模型第一轮等级；同模型重复判断仍不是独立领域人员复核。分歧写入文件，未裁决不得宣称验收完成。不报告虚构的双人Kappa。

无答案题是冻结语料无法完整支持的假设，需通过全库核验。它可以有1级背景块；发现2～3级证据即触发冲突，不能强行压为0。无答案题单列非空返回率、返回数与得分，不计入普通检索质量宏平均，也不把返回候选直接解释为错误答案。

## 划分与防泄漏

- 开发12题、固定测试36题、挑战12题，共用完整冻结语料。
- 按出题所依据的来源分组；同来源问题和同事实改写同区，跨论文题的来源也归入同区。旧调优来源SnCl4、LiBr/DES及CMF仅作开发组。
- `source_splits.json` 区分已分配和仅作全库干扰的来源。来源文件哈希、规范化相同文本检查及最终正例来源交叉检查用于发现泄漏；穷尽标注完成前不能证明跨来源语义重复全部排除。
- 禁止用固定测试及挑战结果调整chunk、模型、融合或reranker；本任务只构建测评，不进行检索优化。
- 后续正文或问题实质变化应新建版本目录，不覆盖已发布版本。正文与索引不一致时评测应停止。

## 指标与延迟

K取1、3、5、10、20；报告Recall、Precision、HitRate、分级nDCG及MRR@10，逐题宏平均。不足K条时Precision仍除以K。重复ID、越界ID、非法分数均不得悄悄去重或修补后评分。质量排名固定采用每题第一次正式运行，另报告重复运行是否稳定。

每轮20次预热，60题各3次，固定并发1、Top-20、120秒请求上限、随机种子20260916。主延迟为每题三次中位数再统计Mean/P50/P95/P99，同时保留逐请求统计。超时计120000ms；其他失败保留实际耗时并单列。正常、降级和失败分别报告。

`isolated` 模式复用现有 `Pipeline.retrieve`，计时从方法进入到完整返回，包含Embedding网络调用和本地检索，排除答案生成及进程通信；reranker由测试侧包装计时，非重排耗时为同次总耗时减重排耗时的估计。`--offline-bm25` 明确为无Embedding的对照，不是混合检索成功结果。

用户后续授权了生产检索日志写入，因此也提供 `http` 模式。其计时是本机HTTP往返时间，含本地传输及序列化；现有服务 `timings.retrieve` 仅作内部诊断，不能冒充严格的完整服务端边界。运行中服务停止的首轮结果保留为故障记录，不作为稳定基线。标注桥与普通检索不同：它直接做冻结材料的相关性判定，不以生成回答质量作为检索分数。

## 已知局限与验收

- 全量AI判断与复核的实际状态以机器验证报告为准；人工领域复核尚未完成。
- 解析过滤会使个别来源仅剩少量非正文可检索片段，题目不能仅凭论文标题推断有答案。
- 混合切块、重叠文本及不同块长度会影响块级Recall的分母；不为提高指标而合并或重切块。
- 60题规模有限，部分来源集中、语义改写相互关联，不能用小幅分数差异作统计显著性结论。
- 仅3道无答案题；目前检索接口没有独立证据接受阈值，不评估阈值拒答正确率。
- 未覆盖的数据领域不补造问题；未完成的工作明确保留为pending。
