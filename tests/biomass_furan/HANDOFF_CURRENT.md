## 3. 规则与数据入口

### 标注规范（**已冻结**）

| 项 | 值 |
|---|---|
| 路径 | `ANNOTATION_INSTRUCTIONS.md` |
| 版本 | **v4**（含 v3 澄清、v4 指定来源规则） |
| 旧版 | `archive-20260917/ANNOTATION_INSTRUCTIONS.md` |
| 系统提示词 | `annotation_system_prompt.txt`（**已于本轮加强边界规则，见下**） |
| 模型参数 | `annotation_model_config.json` |

**等级定义**：

| 等级 | 含义 |
|---|---|
| 3 | 单独覆盖问题所需的**全部必需事实** + 硬性限定条件 |
| 2 | 直接支持**部分**必需事实，尚缺其他必需内容 |
| 1 | 对回答该题有**可说明的辅助价值**（须归入 5 类之一） |
| 0 | 与这题没有可说明的辅助关系 |

**1 级的 5 类（须在 reason 中指明用哪一类）**：同体系不同条件 / 同原料不同体系 / 同论文方法与数据来源 / 直接相关机理背景 / 不同论文的同类对照

**关键边界**：

- **同论文本身不足以判 1**；仅出现相同物质名称也不足以判 1
- 同论文但话题无关 → **0**
- **同时**换了催化剂与体系（仅同领域）→ **0**
- 其他论文转述第三方工作的综述段 → **0**
- **题目点名了具体文献时**（如「2018 年某综述列出…」）：另一篇论文**独立陈述相同事实**只能判 **1**，不能判 2/3（阈值 ≥2，否则系统没找到指定文献也能命中）
  - 例外：明确**引述或归因于**该文献的块另判
  - **`source_group` 字段只是定位辅助，是否硬性以问题措辞为准**

> **本轮提示词加强内容**：新增 L1a–L1d 规则、明确判 0 情形、要求 `zero_reasons` **按块分组**（`doc2,4: 原因; doc7: 原因`），禁止一句话笼统覆盖原因不同的块。

## 7. 风险与下一步

### 必须保留的分寸

1. **机械校验通过 ≠ 语义正确**
2. **两轮等级一致 ≠ 正确** —— 已实证：q_0002 的两条错误等级在**两轮复测中完全相同**
3. **Agent 复核不得称为人工验收** —— `manual_corrections` 字段名有误导性，其内容为 **Agent 复核**
4. **共享理由确实妨碍发现错误**（模型把「同一篇论文」写成 "other documents" 导致过度降级），但**现有证据只能证明相关，不能证明它就是误判的成因**

### 只保留会影响后续执行的未决问题

| # | 问题 | 已证实 vs 推测 |
|---|---|---|
| **1** | **紧凑输出格式导致约 46% 批次解析失败**（最近 41 个响应中 19 个失败） | **已证实**：`finish_reason` 全为 `stop`（非截断）；失败原因含「等级位数与文档数不符」（5 文档只给 4 位）、「非零等级缺 proof」 |
| 2 | 提示词加强是否加剧了格式问题 | **推测，无对照证据** |
| 3 | Tracking ID 的含义 | **未知** —— DeepSeek 官方文档中无此概念；需用户补充出处 |

### 备选方向（**待审计方选定，勿自行展开方案讨论**）

| 方案 | 依据 | 代价 |
|---|---|---|
| **A. 每批 5 块 → 3 块** | 位数更短，模型出错概率更低 | 批数增至约 404 |
| **B. 回退提示词加强** | 排除自因 | 低，可能无效 |
| **C. 换逐块 JSON 格式**（`parse_response` 已存在） | 不用位数编码，鲁棒性高 | 输出更冗长 |

**不建议**放宽解析容错（如自动补位）—— 会把格式错误变成**静默的错误标签**。
