## 一、输入与输出

**输入**：`tasks/<query_id>.txt`，含题目编号、问题、必须覆盖的事实、参考答案，以及该题的全部候选文本块（每块带 `doc_id`、来源 `source_id`、页码、标题）。

**输出**：`judgments/<query_id>.json`

```json
{"query_id": "q_0003", "judgments": [{"doc_id": "chk_...", "relevance": 0, "evidence_quotes": [], "reason": "..."}, ...]}
```

## 二、等级定义

### 3 级 —— 精确命中

这一块**单独**就覆盖了问题所需的**全部必需事实**，并且满足题目的**硬性限定条件**（如指定的催化剂、原料、条件范围）。

### 2 级 —— 必要证据

这一块**直接支持部分必需事实**，但**尚缺其他必需内容**，需要与其他块组合才能完整回答。

判据是「**是否包含必需事实中的某一项**」，**不是**「是否与其他候选重复」。因此判断 2 级**不需要看到该题的其他候选块**。

> **v3 澄清（消除 v2 中 2/3 级的重叠）**
>
> 判 3 级的唯一标准是「**该块独立覆盖了全部必需事实**」。只要还缺哪怕一项必需事实，**最高只能判 2 级**。
>
> 反向约束：如果某项信息**允许缺失**，就**不要**把它写进该题的必需事实 —— 否则会把本该 3 级的块压成 2 级。
>
> 由此，2 级与 3 级互斥且无重叠：**覆盖全部 = 3；覆盖一部分 = 2。**

### 1 级 —— 有辅助价值（本版重点修订）

块对回答**这个具体问题**有**可说明的辅助价值**，但**不直接支持任何一项必需事实**。

"可说明的辅助价值"指以下之一，且必须能在 `reason` 里**具体指出是哪一种**：

| 类型 | 说明 |
|---|---|
| **同体系不同条件** | 与问题所问实验属同一催化剂/溶剂/原料体系，但条件或产物不同，可作为对照 |
| **同原料不同体系** | 使用问题所问的原料，但走了不同的转化路线 |
| **同论文的方法或数据来源** | 问题所依据那篇论文的实验方法、分析手段、数据口径 |
| **直接相关的机理/背景解释** | 解释了问题所涉及的现象为什么发生，但本身不含该问题的数据 |
| **不同论文的同类对照实验** | 另一篇论文做了可比实验，提供可用于横向对照的数值 |

### 0 级 —— 无关

块与**这个问题**没有可说明的辅助关系。

## 三、判定流程

```
第 1 问：块里有没有问题要的那些必需事实？
    ├─ 全部必需事实都有，一块就能答   → 3 级
    ├─ 有一部分，但还缺其他必需内容   → 2 级
    └─ 一项都没有                     → 进入第 2 问

第 2 问：块对回答这个问题有可说明的辅助价值吗？
         （能对应到上表 5 类中的具体一类，且能在 reason 里写清楚）
    ├─ 能   → 1 级
    └─ 不能 → 0 级
```

---

## 四、1 级与 0 级的边界（正反例，务必对照执行）

**以下情形判 1 级：**

| 情形 | 理由示范 |
|---|---|
| 问题问 A 体系下 X 原料的收率，块讲 **A 体系下 Y 原料**的收率 | "同体系不同原料，可作为对照" |
| 问题问 A 体系的最佳条件，块讲 **A 体系加助剂后**的条件 | "同体系不同条件，可作对照" |
| 块是**问题所依据那篇论文**的分析方法段（如 HPLC 条件） | "该论文的方法段，说明数据口径" |
| 块解释了**问题涉及的机理**，但不含所求数据 | "解释该现象的机理背景" |
| **另一篇论文**做了同类反应的实验，给出可比数值 | "不同论文的同类对照实验" |

**以下情形判 0 级（即使关键词重合、即使同一领域）：**

| 情形 | 理由示范 |
|---|---|
| 问题问糠醛，块讲 **HMF / CMF / 乙酰丙酸 / FDCA** | "不同化学品，反应路线不同" |
| 问题问木聚糖，块讲**木糖/葡萄糖/果糖**的**不同体系**实验 | "不同原料且不同体系" |
| 块只是**同一研究领域**的综述另一章节，对象与体系都不同 | "仅同领域，无该问题的辅助价值" |
| 块只是**参考文献条目**、致谢、期刊页眉 | "无实质内容" |
| 块讲**完全不同的工艺路线**（如热解 vs 水解） | "不同工艺路线" |
| 同一篇论文里**与本问题无关的章节** | "同论文但内容无关" |

> **两个最常见错误**：
> 1. 把"同一篇论文"当成 1 级的充分条件 —— **不成立**，同论文里无关的章节是 0 级。
> 2. 把"同一研究领域"当成 1 级 —— **不成立**，必须能落到上表 5 类之一。
>
> **反向也成立**：不同论文**也可能**是 1 级（同类对照实验），不要因为它不是问题指向的那篇就判 0。

## 五、容易混淆的实体（强制区分）

- 糠醛（furfural）≠ 5-羟甲基糠醛（HMF）≠ 氯甲基糠醛（CMF）≠ 乙酰氨基… ≠ 乙酰丙酸（levulinic acid）≠ FDCA
- 木糖（xylose）≠ 木聚糖（xylan）≠ 葡萄糖（glucose）≠ 果糖（fructose）
- yield（收率）≠ selectivity（选择性）≠ conversion（转化率）
- wt% 与 mol% 不能互换；理论预测值与实验测量值不能互换

## 六、引用要求（硬性）

1. 判 **2 级或 3 级**必须给 `evidence_quotes`：从**该块内部**摘录的**连续原文**。
   - **只能**规范化空白
   - **不得**替换字符（原文若是 `130 ◦C`，不得写成 `130 °C`）
   - **不得**从论文其他页面或块借用
   - **不得**凭知识补写
   - 多处引用用省略号分隔，每段仍须是该块内的连续原文
2. 判 **0 级或 1 级**必须给 `reason`，且理由必须是语义判断，不能写"关键词未命中""不是原始出题块""没有搜到"。
3. **1 级的理由必须明确指出属于上表 5 类中的哪一类。**

---

## 七、作业纪律

- 任务文件里的**每一个块**都要给等级，数量必须与文件声明的块数一致，`doc_id` 必须**逐字复制**任务文件中的值。
- 判断依据是**块的完整内容**，与检索排名无关。
- 与其猜，不如判低：**没有原文依据就不要给 2/3 级**；**说不出辅助价值就判 0 级**。
- 只读任务文件，只写指定的那一个 JSON，**不修改项目里的任何其他文件**。
- 不运行会写库、跑检索或联网的脚本。

## 八、题目明确指定来源时的处理（v4 新增）

**触发条件**：问题措辞**点名了具体文献或具体研究**，例如：

- 「2018年《Recent Trends in the Pretreatment…》综述列出…」
- 「2021年糖混合物/DES-MIBK研究中，…」

此时该来源是**硬性限定条件**，不是定位提示。

> `source_group` 字段可辅助定位，但**不能**把它当作所有题目的硬性过滤条件 —— 是否硬性，**以问题的明确措辞为准**。

### 规则

1. **另一篇论文独立陈述了相同事实** → 判 **1 级**，**不是 2 级**。
   - 它提供相同概念的背景理解，可作对照
   - **不能判 3**：别的论文列了三种组分，**证明不了**指定综述列了那三种
   - **也不能判 2**：相关阈值是 **≥2**。若允许这类记录为 2，则系统**完全没找到指定文献**也可能命中 HitRate 与 MRR，与题意不符
2. **例外**：若某块**明确引述、归因于**该指定文献（如 "as reported in [X]"），按实际内容另判，不受本条限制。
3. **同一论文的不同文件、版本或补充材料**：按**实际来源关系**识别，不机械比较文件 ID。

### 不扩大的部分

- 本条**只适用于题目点名了来源的情况**。
- **未指定来源的一般知识题**，来自不同论文的有效直接证据**仍可判 2/3**。
- 不要推广成「所有不同论文都不能提供直接证据」。
