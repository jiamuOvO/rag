## 五、执行策略（已按审计意见修正）

| 项 | 设定 |
|---|---|
| 并发 | 从 1 起步 |
| 单请求超时 | 180 秒 |
| **认证 / 参数错误（未授权、格式错）** | **立即停止并修正**，**不重试** |
| **429 限流** | 按服务方提示，**在总预算内**有限重试 |
| **5xx / 连接错误** | 有限重试（最多 2 次） |
| **超时** | 可能**已产生费用** → **重试必须计入预算** |
| 连续失败熔断 | 连续 3 次失败即停止，人工介入 |
| 保存粒度 | 每批落盘 |
| 断点恢复 | 已完成批次跳过 |

### API 的潜在收益（修正表述）

除并发外，还包括**减少 Agent 工具调用与对话调度开销**。

> **实际收益仍以试跑为准**，不预设结论。
